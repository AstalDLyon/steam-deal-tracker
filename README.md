# Nome do Projeto
Steam Deal Tracker

## Visão Geral
Um rastreador de promoções da loja steam
Embora exista sites que fazem  até melhor o que esse programa propõe. Eu decidi tentar criar uma versão que rode localmente, com uma base de dados level como SQLlite.
Esse projeto não é de forma alguma superior a versões como "SteamDB" ou "IsThereAnyDeal?". na verdade, eu acabei descobrindo que ele vai  ser bem impreciso, ja que até o momento que escrevo isso, somente empresas tem acesso a algumas API da steam.

### Porque não rastreiar direto do SteamDB?
O "SteamDB", não tem API e eu não irei fazer webscraping no serviço deles.
